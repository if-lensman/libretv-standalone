# 片刻 0.21.1

- 影视与直播订阅增加自动更新频率：每次打开 App、每天、每周或仅手动，直播另可选每 6 小时。未设置过频率时默认每次打开检查，保留已有频率或关闭选择。
- 电视从后台返回频道页时重新检查订阅并同步列表，适用于 NAS 等固定地址提供的清单内容变化。
- 订阅更新重新验证缓存；更新失败时保留原来源和频道，可随时立即更新并查看成功时间或失败状态。
- 影视订阅链接持续保存，刷新补充新增来源、更新同地址来源信息，保留停用状态，不恢复已删除的来源；上游移除的旧来源可手动清理。
- 已保存的直播链接和单个 CMS 影视接口无需删除重加。旧版通过影视清单订阅导入、且未保留原清单链接的配置，需要补一次该链接才能持续更新清单。文件与 JSON 文本仍需重新导入。

自动检查在打开 App 时按频率进行，关闭后不运行定时任务。正式包不内置影视来源或直播订阅；沿用原签名，覆盖安装保留配置、收藏与观看进度，支持 Android 6.0 及以上。
