# 片刻 0.20.0

留点片刻，看点喜欢的。

- 触摸端跟随系统方向：手机竖屏保留底部导航，车机、平板和手机横屏使用侧边导航；横屏详情/设置支持双列，适配16:9和4:3布局。
- 旋转时保留当前页面、输入草稿、搜索结果及剧集；横屏进入播放后，返回不再强制切回竖屏。
- TV点播恢复隐藏控制栏时的左右快退/快进10秒，长按逐步加速；控制栏改为两排扁按钮，倍速、快退与快进直接可见。
- 手机扫码添加来源提供三种单选方式：逐条填写、导入JSON文本、订阅地址；逐条整理后统一发送到电视确认。
- 车机/平板沿用手机端对应的点播、直播触摸操作；直播保持正常播放速度。

Android 6.0及以上。沿用原包名、签名和更新地址，可在“设置 → 检查更新”覆盖升级，保留本机来源、收藏和观看记录。公开安装包不内置影视来源或直播订阅，请自行配置。
