# 投屏客户端后续计划

状态：候选计划，暂不实施。当前仍以片刻手机与电视影音客户端为主。

## 已有基础

手机端已接入 UPnPCast，具备设备发现、点播/部分直播直链发送、播放暂停停止、进度音量控制、记录与恢复控制。设备接收指令不等于已经实际播放，需保留明确反馈。

## 分阶段候选

1. 整理现有体验：明确连接设备入口、当前投屏卡片和统一控制页，复用现有协议与选集流程。
2. 外部内容入口：粘贴 HTTP(S) 视频直链、系统分享接入；校验地址，区分网页地址与媒体地址。
3. 本地视频：文件选择、内容URI授权、局域网文件服务、后台生命周期及断连恢复。底层库有能力，尚需App完整接入。
4. 特殊来源：按实际需求评估带请求头/鉴权媒体的中转；另行设计访问边界、资源占用及失败反馈。

以上各阶段独立确认范围；不包含手机整屏镜像、通用网页视频捕获、多协议全设备兼容。

## 工作量判断与验收

现有选片投屏入口整理相对较小；外部分享与本地视频为中等功能；镜像为独立大功能。没有真实设备测试前不承诺工期或兼容型号。验收需覆盖发现、可见视频/声音、控制读回、切集、锁屏、断网与重新连接，不能只看模拟器或协议返回成功。
