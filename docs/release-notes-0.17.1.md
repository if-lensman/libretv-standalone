# 0.17.1

## 手机播放手势修正

- 单击画面只显示或收起控制栏，不再改变播放进度。
- 双击画面左侧后退10秒，双击右侧前进10秒。
- 保留滑动调整进度、亮度、音量和进度条拖动；画面上不增加快进退按钮。

## 播放页焕新

- 手机竖屏上方视频、下方选集，支持收藏、前后集、倍速、字幕和自动下一集。
- 手机横屏采用轻量浮层，进度条与操作栏使用连续渐变。
- TV 单排操作与粉色遥控焦点，遥控器左右键快进退。
- 从头播放，以及横屏、TV 的自动下一集设置收进“更多”。

Android 6.0 及以上。沿用原签名，可覆盖升级并保留本机数据。公开安装包不内置视频源或直播源，请自行配置。
