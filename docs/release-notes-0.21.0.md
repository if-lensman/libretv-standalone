# 片刻 0.21.0

- 手机竖屏、横屏和电视播放控制栏增加「设置片头」「设置片尾」「自动跳过」，无需进入更多菜单。
- 播放到正片开始或片尾开始的位置，点一下即可标记，不用手算或输入秒数；标记后自动开启。
- 同一剧名的设置保存在本机，全集沿用，换源后也保留；带不同季数或版本后缀的剧名分别记忆。
- 剧集详情与选集时显示已保存的片头、片尾和开关状态；设置独立保存，取消收藏也保留。
- 片尾按剩余时长匹配每集，跳过前提供5秒倒计时，可以取消并继续看片尾。
- 续播保留上次进度，手动拖回片头片尾允许观看；片尾跳过后遵循自动下一集设置，最后一集停止。

正式安装包不内置影视源或直播源。沿用原有签名，覆盖安装保留本机配置与进度，支持Android 6.0及以上系统。
