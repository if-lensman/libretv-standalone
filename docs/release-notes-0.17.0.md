# 0.17.0

## 播放页焕新

- 手机竖屏改为上方视频、下方选集，支持收藏、前后集、倍速、字幕和自动下一集。
- 手机横屏采用轻量浮层，统一图标与粉色强调色，减少按钮遮挡。
- TV 操作区改为单排布局，突出遥控器焦点。
- 从头播放，以及横屏、TV 的自动下一集设置收进“更多”。

## 交互与显示修复

- 移除常驻快进、快退按钮：手机轻点画面左侧后退10秒、右侧前进10秒；TV 使用遥控器左右键。
- 修复手机横屏进度条与操作栏之间的渐变断层。
- 修复收藏文字裁切、横屏操作按钮显示不完整的问题。
- 控制层即时显示、收起，避免过渡动画影响快速点按。

Android 6.0 及以上。沿用原签名，可覆盖升级并保留本机数据。公开安装包不内置视频源或直播源，请自行配置。
