# 片刻 0.19.0

留点片刻，看点喜欢的。

- 应用对外名称改为「片刻」，接入新的矢量字标；仓库地址、包名与更新入口保持不变。
- 手机与 TV 的历史页加入封面和观看进度，突出继续观看，清理操作收进管理入口。
- 收藏与片单采用图片卡片，精简重复按钮，移出片单仍保留观看历史。
- 影片详情突出主要播放入口，收藏、片单和剧集各有位置。
- 设置按内容来源、播放与显示、应用分组；视频来源与直播订阅分别管理，保留添加反馈和删除确认。
- TV 同步统一页面导航与遥控焦点样式；更新页加入片刻名称与宣传语，保留原有更新方式。

Android 6.0 及以上。已安装用户可在「设置 → 检查更新」直接升级，保留本机来源、收藏和观看进度。公开安装包不内置视频源或直播源，请自行配置。

部分业务设计与解析逻辑参考 LibreTV，原项目说明和第三方致谢继续保留。
