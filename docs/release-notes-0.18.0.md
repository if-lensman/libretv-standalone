# 0.18.0

## 直播播放页焕新

- 手机竖屏上方看直播、下方按分类选台；横屏使用轻量浮层，支持直接展开频道分类。
- TV 播放控件精简为单排，使用清晰的遥控焦点和左右方向键提示。
- “上一个 / 下一个”切换频道；TV 左右键直接切台，上下键打开频道分类。
- 分类保留“全部、收藏”和直播订阅里的频道分组，可在当前分类内循环切台。
- 打开频道分类后，方向键只移动焦点，避免误切台；当前频道和遥控焦点分别突出显示。
- 保留直播收藏、换线路、回到直播和故障恢复；手机横竖屏切换保持播放。

Android 6.0 及以上。已安装用户可在“设置 → 检查更新”直接更新，保留本机配置。公开安装包不内置视频源或直播源，请自行配置。
